# Sales Database — Customer & Product CRUD

A Java application for managing customers and products through
CRUD operations connected to a PostgreSQL database.

## About

This project focuses on backend development and database integration
using Java and PostgreSQL.

The application implements CRUD operations for customer and product
data, with database access handled through Java and SQL.

The project was developed to practice the interaction between a Java
application and a relational database, including data creation,
retrieval, updating, and deletion.

## Features

- Customer registration
- Customer data retrieval
- Customer data update
- Customer deletion
- Product management
- Database persistence
- SQL database operations

## Technologies

- Java 21
- PostgreSQL
- JDBC
- Maven
- JUnit
